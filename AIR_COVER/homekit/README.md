## 1. 產品簡介

AirCover 是 AUTOMATE 推出的智能捲簾控制升級套件 — **替換 Tuya 捲簾 / 窗簾控制器原廠的 CB3S Wi-Fi 模組**,讓本來只能用 Tuya/Smart Life App 控制的傳統 Tuya 捲簾,**直接加入 Apple 家庭（Apple HomeKit）**,不需專屬 Hub 也不必雲端帳號。

主要特性:
- **無痕升級** — 接腳完全相容 CB3S,焊上即用,不用換馬達 / 軌道 / 控制器
- **原生 Apple HomeKit** — 直接加入 Apple 家庭,支援 Siri 語音與自動化,無需專屬 App
- **精確位置控制** — 0–100% 任意位置（視原廠馬達能力）
- **本地控制** — Wi-Fi 斷線時仍可用實體按鈕操作,不靠雲端
- **與原廠遙控 / App 並存** — 你既有的實體遙控、Tuya App、本地按鍵都還能用

### 1.1 規格速覽

| 項目 | 內容 |
|---|---|
| 通訊協定 | **Apple HomeKit over Wi-Fi** |
| 控制協定 | Tuya MCU UART（原廠通訊規格 9600 8N1） |
| Wi-Fi | 2.4 GHz 802.11 b/g/n（**不支援 5 GHz**） |
| BLE | 5.0（僅配對輔助） |
| 處理器 | ESP32-C3（RISC-V 160 MHz） |
| Flash | 4 MB |
| 模組形式 | 取代 Tuya CB3S 模組,接腳相容 |
| 供電 | 由原機台 3.3V VCC 供電（<100 mA） |
| 工作環境 | -10 – 60 °C / 10 – 90% RH（無凝結） |

### 1.2 包裝內容

- AirCover 模組（已焊好排針）× 1
- 快速入門卡（含 HomeKit 設定碼與 QR Code）× 1

### 1.3 相容性

✅ **可用**:Tuya 通訊協定的捲簾 / 窗簾 / 百葉控制器（DP1=控制 / DP2=百分比 / DP3=位置回報 / DP5=方向）
- 多數 Tuya 認證的捲簾馬達 / 軌道 / 百葉
- 常見 LoraTap、Zemismart、Aubess、Moes 等品牌的 Tuya 版本

❌ **不支援**:
- Zigbee 版本（完全不同協定）
- Wi-Fi 但不是 Tuya 系統（例如走 Aqara / Yeelight 自家協定）
- 紅外控制 / 433 MHz 控制器

**判斷方式**:看原機台拆開後的模組編號 — 若是 `CB3S` 字樣的方形模組就可用。

> ⚠️ 本產品為 **Apple HomeKit 版**。HomeKit 配件由 Apple 家庭原生支援;**不支援** Google Home / Amazon Alexa 直接接入（那需要 [Matter 版本](https://github.com/Billtou/public/tree/main/AIR_COVER/matter)）。進階可經 Home Assistant 的「HomeKit 控制器」整合（章節 5.3）。

### 2.1 外觀與接口

- **PCB 模組** — 1.27 cm × 2.4 cm,跟 CB3S 同尺寸

## 3. LED 狀態指示

依優先級從高到低:

| 優先級 | 狀態 | LED 行為 | 含義 |
|---|---|---|---|
| 1 | 重置警告 | 5 Hz 快閃（亮 0.1s 暗 0.1s） | 按鍵已按 5 秒,再 5 秒就執行工廠重置 |
| 2 | 等待 Wi-Fi | 閃 1 下 + 停 1.8s | 尚未設定 Wi-Fi / Wi-Fi 連不上 |
| 3 | 未配對 / 配對中 | 雙閃 + 停 1.4s | Wi-Fi 已連,尚未加入 Apple 家庭 |
| 4 | 正常運作 | 熄滅 | 已加入家庭,一切就緒 |

| 看到 LED | 通常代表 | 該做什麼 |
|---|---|---|
| 閃 1 下 | 沒設定過 Wi-Fi / 重置後 | 先連設定熱點設 Wi-Fi（章節 5.1） |
| 雙閃 | Wi-Fi 已連,還沒加入家庭 | 用「家庭」App 加入配件（章節 5.2） |
| 熄滅 | 已上線運作中 | 無需處理 |
| 快閃 | 你正在長按重置鍵 | 想取消就放開;想重置就按到 10 秒 |

## 4. 按鍵操作

> ⚠️ 本章節是 **AirCover PCB 板上的按鍵**,需要打開原機台外殼才能按。
> **日常 user 不需要動到** — 重置請優先用 [章節 9.1 原機台對碼鍵](#91-用原機台對碼鍵推薦免拆殼)（免拆殼）。

| 動作 | 結果 |
|---|---|
| 按住 < 5 秒後放開 | 切換捲簾狀態 — 開→關 / 關→開 |
| 持續按住達 5 秒 | LED 開始**快閃**（警告中,放開可取消） |
| 持續按住達 10 秒 | **工廠重置觸發**,LED 熄滅,裝置自動重啟 |

## 5. 接入 Apple 家庭（初次設定）

HomeKit 版採 **兩步驟**:先用設定熱點設好 Wi-Fi,再加入 Apple 家庭。

**設定前確認:**
- [ ] 路由器 **Wi-Fi 2.4 GHz** 可用（AirCover 不支援 5 GHz）
- [ ] iPhone / iPad 已登入 iCloud 並啟用「家庭」
- [ ] 家中有一台 HomeKit 中樞（HomePod / Apple TV）可獲得遠端控制與自動化（非必要但建議）

### 5.1 先設定 Wi-Fi（SoftAP）

1. 通電 AirCover,等狀態 LED **閃 1 下 + 停**（代表尚未設定 Wi-Fi）
2. 手機 Wi-Fi 清單連上熱點 **`automate-aircover-XXXXXX`**（無密碼）
3. 手機通常自動彈出設定頁;若無,瀏覽器開 `http://192.168.4.1/`
4. 選您的家用 Wi-Fi（2.4 GHz）→ 輸入密碼 → 儲存
5. AirCover 自動重啟並連上家用網路,LED 轉為**雙閃**（等待加入家庭）

### 5.2 加入 Apple 家庭

1. iPhone 開「家庭」App → 右上角 **+** → **加入配件**
2. 掃描機身 / 快速入門卡上的 **HomeKit QR Code**;或選「更多選項」→ 手動輸入設定碼 `111-88-999`
3. 配對完成 → LED **熄滅**,出現「窗簾」配件
4. 命名 + 加入房間 → 可拉開關 / 設位置 / 加自動化 / Siri 語音

### 5.3 進階：Home Assistant（HomeKit）

Home Assistant 可用內建的 **「HomeKit 控制器（HomeKit Controller）」** 整合接入本配件:

1. HA → 設定 → 裝置與服務 → 新增整合 → **HomeKit Controller**
2. 選到 `AirCover-XXXXXX` → 輸入設定碼 `111-88-999`
3. 完成後出現 `cover` 實體

> ⚠️ 一個 HomeKit 配件同一時間只綁定**一個** HomeKit 家庭 / 控制器。若已加入 Apple 家庭,要改由 HA 直接控制需先在 Apple 家庭移除配件再加入 HA（反之亦然）。若要同時被多平台控制,請改用 [Matter 版本](https://github.com/Billtou/public/tree/main/AIR_COVER/matter)。

## 6. 捲簾控制

### 全開 / 全關 / 暫停

| 動作 | Apple 家庭 App | Siri | 對應指令 |
|---|---|---|---|
| **全開** | 拉到 100% / 按「打開」 | 「打開客廳窗簾」 | Tuya DP1 = open |
| **全關** | 拉到 0% / 按「關閉」 | 「關閉客廳窗簾」 | Tuya DP1 = close |
| **暫停** | 運轉中再按一次 | — | Tuya DP1 = stop |

### 精確位置（0–100%）

Apple 家庭 App 拉桿支援 0–100% 任意值:
- **100%** = 完全打開　**0%** = 完全關閉　**50%** = 半開

> 實際定位精度依原機台馬達能力 — 高階捲簾通常 ±1%,入門款可能跳格 5–10%。

### 自動化情境

窗簾在 Apple 家庭「自動化」中可當作**動作**:早晚定時開關、日出日落聯動、離家/回家聯動等,皆在「家庭」App 內設定,**不需 AirCover 額外配置**。

## 7. Web UI 進階設定

配對成功後,AirCover 在區網提供 Web UI。瀏覽器網址兩種擇一:
- **直接 IP**:在「家庭」App 內查看裝置 IP（例 `http://192.168.1.123`）
- **主機名稱**:`http://automate-ahp-aircover-XXXXXX.local`

> 手機 / 電腦與 AirCover 必須在**同一個 Wi-Fi 網段**。

| 頁面 | 內容 |
|---|---|
| **首頁** | 裝置資訊（韌體 / 記憶體 / 運行時間 / 連線狀態 / 製造日期）+ **窗簾控制**（目前位置、開/關/停、0–100% 滑桿）+ 使用說明連結 |
| **版更頁** | 韌體版本、一鍵 OTA、系統日誌、裝置資料清除 |

## 8. OTA 韌體更新

1. 連線 Web UI → 底部 **版更** Tab
2. 系統自動向官方 GitHub 檢查最新版本
   （[AIR_COVER/homekit/firmware-w](https://github.com/Billtou/public/tree/main/AIR_COVER/homekit/firmware-w)）
3. 若有新版 → 「開始更新」→ 自動下載 + 安裝 + 重啟（約 1–2 分鐘）

更新期間裝置暫時離線,**捲簾位置不會亂動**。

| 項目 | 是否保留 |
|---|---|
| HomeKit 配對 | ✅ 保留 |
| Wi-Fi 帳密 | ✅ 保留 |
| 捲簾目前位置 | ✅ 保留 |
| 韌體版本 | ❌ 換新版 |

> ⚠️ 更新中**請勿斷電**。異常時雙分區設計會自動回到上一版。

## 9. 工廠重置

### 9.1 用原機台對碼鍵（推薦,免拆殼）

> 💡 最簡單,**完全不用拆機殼**。

按你**原機台**（Tuya 捲簾控制器）上的「**對碼鍵 / 配網鍵 / WiFi 鍵**」— 觸發方式依原機台 OEM 設定,常見**連按 3 下 + 持續 2 秒** 或 長按 5–10 秒（請查原機台說明書「重設 Wi-Fi」段落）。

成功觸發後,AirCover 自動清除 HomeKit 配對 + Wi-Fi → 3 秒重啟 → LED 轉單閃（等待重新設定）。

### 9.2 Web UI 重置

- 開 `http://automate-ahp-aircover-XXXXXX.local/update`
- 「裝置資料清除」card → 確認 → 自動重啟

### 9.3 硬體重置（需拆殼）

> ⚠️ 只有原機台對碼鍵壞掉才用。打開外殼,按住 AirCover 板上按鍵 5 秒（LED 快閃）→ 續按到 **10 秒** → 重置觸發。5–10 秒間放手 = 取消。

### 重置會清除什麼

| 項目 | 是否清除 |
|---|---|
| HomeKit 配對 | ✅ 清除 |
| Wi-Fi 帳密 | ✅ 清除 |
| 韌體版本 / 裝置憑證 | ❌ 不變 |
| 捲簾當下位置 | ❌ 不變（實體狀態） |
| 原機台 Tuya App 配對 | ❌ 不變（獨立雲端配對） |

> 重置後跟全新開封一樣,需重新設定 Wi-Fi 並加入 Apple 家庭。原機台馬達 / 行程 / 遙控對碼都不受影響。

## 10. 故障排除

### 配對相關

| 現象 | 原因 | 處理 |
|---|---|---|
| 連不到設定熱點 | 未進入設定模式 / 已設過 Wi-Fi | 確認 LED 閃 1 下;必要時先重置（章節 9） |
| 「家庭」App 找不到配件 | Wi-Fi 沒設好 / 手機藍牙關 / 不同網段 | 確認已完成章節 5.1、藍牙開、手機連同一 2.4 GHz |
| 顯示「無法加入」 | 設定碼錯 / 已被其他家庭綁定 | 重輸 `111-88-999`;曾配對過先重置 |
| 想改 Wi-Fi / 已從家庭刪除想重來 | 需重置 | 按原機台「對碼鍵」（章節 9.1） |

### 控制相關

| 現象 | 原因 | 處理 |
|---|---|---|
| 按開/關不動 | 接線異常 / Tuya MCU 沒回應 | 拆殼檢查 UART 接線（TX/RX 沒接反） |
| 開到一半就停 | 原機台行程限位設錯 / 物理障礙 | 用原廠遙控學習行程後再控制 |
| 位置回報跟實際不同步 | 原機台 percent_state 沒回報 | 長按「全開→全關」走完整行程一次校正 |
| 家庭顯示「無回應」 | Wi-Fi 斷線 / 路由器太遠 | 確認 Wi-Fi RSSI > -70 dBm；重啟路由器 |
| 暫停沒效果 | 部分廉價馬達不支援動作中暫停 | 取決於原機台馬達 |

### OTA 相關

| 現象 | 原因 | 處理 |
|---|---|---|
| 「無法取得版本」 | 連不到 GitHub | 檢查網路 / DNS |
| 更新卡在 0% | 下載卡住 | 等 5 分鐘;不行就重啟再試 |
| 更新失敗 | 供電不足 | 重啟（回舊版）,確認供電後重試 |

## 11. 安全使用

- ⚡ **接線前務必斷電** — 原機台通常接 110/220V AC,模組焊接時必須整個拔插頭
- 🔌 **不可碰原廠 110/220V 部分** — AirCover 只接低壓 3.3V UART 端,馬達電源由原機台處理
- 🌡 工作環境 -10 – 60 °C,**勿安裝於陽光直曬 / 廚房油煙環境**
- 🌧 戶外捲簾使用須確認原機台防水等級,AirCover 模組不防水
- ⚠️ **改裝可能讓原機台失去保固** — 由消費者自行承擔
- 🔧 **建議由電器專業人員施工** — 焊接 / 拆卸請找有經驗的人
