## 1. 產品簡介

主要特性:
- **原生 Apple HomeKit** — 直接加入 Apple 家庭,支援 Siri 語音與自動化,無需專屬 App
- **精確位置控制** — 0–100% 任意位置（視原廠馬達能力）
- **本地控制** — Wi-Fi 斷線時仍可用遙控器實體按鈕操作,不靠雲端

## 3. 接入 Apple 家庭（初次設定）

HomeKit 版採 **兩步驟**:先用設定熱點設好 Wi-Fi,再加入 Apple 家庭。

**設定前確認:**
- [ ] 路由器 **Wi-Fi 2.4 GHz** 可用（AirCover 不支援 5 GHz）
- [ ] iPhone / iPad 已登入 iCloud 並啟用「家庭」
- [ ] 家中有一台 HomeKit 中樞（HomePod / Apple TV）可獲得遠端控制與自動化（非必要但建議）

### 3.1 先設定 Wi-Fi（SoftAP）

1. 通電 AirCover,等狀態 LED **閃 1 下 + 停**（代表尚未設定 Wi-Fi）
2. 手機 Wi-Fi 清單連上熱點 **`automate-aircover-XXXXXX`**（無密碼）
3. 手機通常自動彈出設定頁;若無,瀏覽器開 `http://192.168.4.1/`
4. 選您的家用 Wi-Fi（2.4 GHz）→ 輸入密碼 → 儲存
5. AirCover 自動重啟並連上家用網路,LED 轉為**雙閃**（等待加入家庭）

### 3.2 加入 Apple 家庭

1. iPhone 開「家庭」App → 右上角 **+** → **加入配件**
2. 掃描機身 / 快速入門卡上的 **HomeKit QR Code**;或選「更多選項」→ 手動輸入設定碼 `111-88-999`
3. 配對完成 → LED **熄滅**,出現「窗簾」配件
4. 命名 + 加入房間 → 可拉開關 / 設位置 / 加自動化 / Siri 語音

### 3.3 進階：Home Assistant（MQTT）

AirCover 可透過 **MQTT** 直接接上 Home Assistant。MQTT 與 HomeKit 配對**互不干擾**,可與 Apple 家庭**並存**,不需從 Apple 家庭移除配件。

**前置**:一台 MQTT Broker（例如 HA 的 Mosquitto broker add-on),且與 AirCover 在同一網段。
**在HA先建立一個一個使用者，名稱 mqtt-user 密碼 mqtt-pass 在到窗簾端的ip網頁填入該內容即可**
1. 開 AirCover Web UI → 底部 **工程模式** 分頁 → 找到「**MQTT / Home Assistant**」卡（此卡免登入即可編輯）
2. 填入 **Broker IP**、**Port**（預設 `1883`）、**Username**、**Password**
3. 按「**連線測試**」確認可連 → 再按「**儲存並啟用**」
4. HA 端裝好 **MQTT 整合**後,會自動探索到一顆窗簾實體 **`cover.aircover_XXXXXX`**（裝置名 `AirCover-XXXXXX`),支援開 / 關 / 停與 0–100% 位置控制

> HA 位置慣例與本卡一致:**100% = 全開、0% = 全關**。要停用或清除設定,同卡的「停用 / 刪除設定」即可。

## 4. Web UI 進階設定

配對成功後,AirCover 在區網提供 Web UI。瀏覽器網址兩種擇一:
- **直接 IP**:在「家庭」App 內查看裝置 IP（例 `http://192.168.1.123`）
- **主機名稱**:`http://automate-ahp-aircover-XXXXXX.local`

> 手機 / 電腦與 AirCover 必須在**同一個 Wi-Fi 網段**。

| 頁面 | 內容 |
|---|---|
| **首頁** | 裝置資訊（韌體 / 記憶體 / 運行時間 / 連線狀態 / 製造日期）+ **窗簾控制**（目前位置、開/關/停、0–100% 滑桿）+ 使用說明連結 |
| **版更頁** | 韌體版本、一鍵 OTA、系統日誌、裝置資料清除 |

## 5. OTA 韌體更新

1. 連線 Web UI → 底部 **版更** Tab
2. 系統自動向官方 GitHub 檢查最新版本
   （[AIR_COVER/homekit/firmware-w](https://github.com/Billtou/public/tree/main/AIR_COVER/homekit/firmware-w)）
3. 若有新版 → 「開始更新」→ 自動下載 + 安裝 + 重啟（約 1–2 分鐘）

更新期間裝置暫時離線,**捲簾位置不會亂動**。

| 項目 | 是否保留 |
|---|---|
| HomeKit 配對 | ✅ 保留 |
| Wi-Fi 帳密 | ✅ 保留 |
| 捲簾目前位置 | ✅ 保留 |
| 韌體版本 | ❌ 換新版 |

> ⚠️ 更新中**請勿斷電**。異常時雙分區設計會自動回到上一版。

## 6. 工廠重置

> ℹ️ 「重置」有**兩種完全不同**的意思,請先分清楚:
> - **重置 AirCover 配對**（§6.1 / §6.2）— 清掉 HomeKit + Wi-Fi,讓模組回到待設定狀態。**捲簾行程不受影響**。
> - **重設捲簾馬達行程 / 上下限**（§6.3）— 這是**原廠馬達自己的功能**,用原廠遙控操作,**與 AirCover 無關**。

### 6.1 重置 AirCover 配對 — 用原機台對碼鍵（推薦,免拆殼）

> 💡 最簡單,**完全不用拆機殼**。

**連續按3下電機底部的配對建後在長按2秒至指示燈快閃 "見說明書的解網方法"**


### 6.2 重置 AirCover 配對 — Web UI

- 開 `http://automate-ahp-aircover-XXXXXX.local/update`
- 「裝置資料清除」card → 確認 → 自動重啟

**重置會清除什麼**

| 項目 | 是否清除 |
|---|---|
| HomeKit 配對 | ✅ 清除 |
| Wi-Fi 帳密 | ✅ 清除 |
| 韌體版本 / 裝置憑證 | ❌ 不變 |
| 捲簾當下位置 | ❌ 不變（實體狀態） |
| 原機台 Tuya App 配對 | ❌ 不變（獨立雲端配對） |

> 重置後跟全新開封一樣,需重新設定 Wi-Fi 並加入 Apple 家庭。原機台馬達 / 行程 / 遙控對碼都不受影響。

### 6.3 重設捲簾馬達行程 / 上下限（原廠馬達功能）

> ⚠️ 這是**原廠馬達本身**的功能,**不經過 AirCover**。AirCover 只轉發開 / 關 / 位置指令,無法設定或重置行程,按 AirCover 板子或原機台「配網鍵」都不會動到行程。

捲簾的「全開 / 全關」實體極限(行程)存在**原廠馬達**裡。若安裝後發現全開 / 全關位置跑掉、或百分比對不上實際,需要重設馬達行程:

- 用**原廠遙控器**依原廠說明書操作。多數電動捲簾 / Tuya 馬達的行程學習,常見為遙控上的「**設定鍵(P / SET,或停止鍵長按)**」搭配上 / 下鍵進入行程設定模式,或馬達本體上的行程設定鈕。
- **實際按鍵組合依你的馬達型號而定** — 請查原廠馬達 / 遙控說明書的「行程設定 / 極限設定 / limit setting」段落。

> 行程重設完成後,若 AirCover 顯示的位置仍對不上,長按「全開 → 全關」走完一次完整行程,讓位置回報自動校正(見章節 7)。

## 7. 故障排除

### 配對相關

| 現象 | 原因 | 處理 |
|---|---|---|
| 連不到設定熱點 | 未進入設定模式 / 已設過 Wi-Fi | 確認 LED 閃 1 下;必要時先重置（章節 6） |
| 「家庭」App 找不到配件 | Wi-Fi 沒設好 / 手機藍牙關 / 不同網段 | 確認已完成章節 3.1、藍牙開、手機連同一 2.4 GHz |
| 顯示「無法加入」 | 設定碼錯 / 已被其他家庭綁定 | 重輸 `111-88-999`;曾配對過先重置 |
| 想改 Wi-Fi / 已從家庭刪除想重來 | 需重置 | 按原機台「對碼鍵」（章節 6.1） |


### OTA 相關

| 現象 | 原因 | 處理 |
|---|---|---|
| 「無法取得版本」 | 連不到 GitHub | 檢查網路 / DNS |
| 更新卡在 0% | 下載卡住 | 等 5 分鐘;不行就重啟再試 |
| 更新失敗 | 供電不足 | 重啟（回舊版）,確認供電後重試 |

## 8. 安全使用

- ⚡ **接線前務必斷電** — 原機台通常接 110/220V AC,模組焊接時必須整個拔插頭
- 🔌 **不可碰原廠 110/220V 部分** — AirCover 只接低壓 3.3V UART 端,馬達電源由原機台處理
- 🌡 工作環境 -10 – 60 °C,**勿安裝於陽光直曬 / 廚房油煙環境**
- 🌧 戶外捲簾使用須確認原機台防水等級,AirCover 模組不防水
- ⚠️ **改裝可能讓原機台失去保固** — 由消費者自行承擔
- 🔧 **建議由電器專業人員施工** — 焊接 / 拆卸請找有經驗的人
