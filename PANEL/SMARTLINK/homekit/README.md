<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">1. 產品簡介</h2>

SmartLink 是 AUTOMATE 的 3.95" 房間總控面板。裝在床頭或入門口,一面牆就能看完整個房間的狀態並直接控制。

面板同時走兩條路:

<table style="width:100%;border-collapse:separate;border-spacing:8px;margin:16px 0">
<tr>
<td width="50%" style="background:#fff;padding:16px;border-radius:14px;border:1px solid #e5e7eb;box-shadow:0 2px 8px rgba(0,0,0,0.04)">
<p style="margin:0;font-weight:700;color:#1c3d5a">🏠 Apple Home</p>
<p style="margin:6px 0 0;font-size:13px;color:#5a6a7a">面板本身加入 HomeKit,提供情境按鍵與「全部關閉」</p>
</td>
<td width="50%" style="background:#fff;padding:16px;border-radius:14px;border:1px solid #e5e7eb;box-shadow:0 2px 8px rgba(0,0,0,0.04)">
<p style="margin:0;font-weight:700;color:#1c3d5a">🧩 Home Assistant</p>
<p style="margin:6px 0 0;font-size:13px;color:#5a6a7a">把 HA 裡的燈、風扇、窗簾、門鎖等拉進面板直接控制</p>
</td>
</tr>
</table>

面板上的「磚牆」由兩種來源組成:

| 來源 | 說明 | 上限 |
|---|---|---|
| **Automate 裝置** | 同網段的 AUTOMATE 自家產品,面板自動發現、勾選即上牆 | 24 台 |
| **Home Assistant** | 從 HA 匯入的裝置(需權杖授權,見[第 5 章](#5-接入-home-assistant權杖授權)) | 24 個 |

<blockquote style="border-left:4px solid #007AFF;background:#eff7ff;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#1c3d5a">
💡 兩種來源可以混用。Automate 裝置不需要 HA 也能控制;HA 匯入則讓面板一併管理第三方品牌的裝置。
</blockquote>

</blockquote>

**怎麼確認連上了?**
面板 **齒輪 → 導入** 分頁有兩列:

- **連網狀態** — 顯示訊號強度百分比(顯示 `--` 代表未連線)
- **網路位置** — 顯示面板取得的 IP,例如 `192.168.1.50`

這個 IP 就是[第 4 章](#4-進入面板網頁設定)要用的網頁位址。

<blockquote style="border-left:4px solid #007AFF;background:#eff7ff;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#1c3d5a">
💡 訊號低於 65% 建議把面板的「不睡眠」打開(詳細頁的 ⓘ 說明有寫),可減少弱訊號下的斷線。
</blockquote>

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">3. 加入 Apple 家庭</h2>

1. 確認家中有 **Home Hub**(HomePod / Apple TV / 常駐家中的 iPad)—— HomeKit 遠端控制必要
2. 面板上進入 **齒輪 → 面板** 分頁,會看到三個 QR Code
3. iPhone 開 **家庭 App** → 右上 **＋** → **加入配件**
4. 掃描中間標示 **Homekit** 的 QR Code
5. 依畫面指示完成,約 30–60 秒;命名與分配房間 → 完成

<blockquote style="border-left:4px solid #007AFF;background:#eff7ff;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#1c3d5a">
💡 掃不到 QR 時可選「沒有代碼或無法掃描」→ 手動輸入 QR 下方顯示的 8 位數配對碼。
</blockquote>

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">4. 進入面板網頁設定</h2>

HA 授權與裝置匯入都在**面板的網頁**上操作(不是在面板螢幕上打字)。

1. 手機或電腦連上**與面板同一個** Wi-Fi
2. 瀏覽器輸入面板 IP,例如 `http://192.168.1.50`
   - IP 在面板 **齒輪 → 導入 → 網路位置** 那一列
   - 也可以直接掃 **齒輪 → 面板** 分頁右邊那個標示 **面板後台** 的 QR Code
3. 網頁下方有分頁列:**首頁 / HA導入 / 版更**

### 5.2 填進面板網頁

面板網頁 → **HA導入** 分頁 → 最上方的「Home Assistant 連線」卡片:

| 欄位 | 填什麼 | 範例 |
|---|---|---|
| **主機(IP 或網域)** | HA 的位址,**不要加 `http://`** | `192.168.1.10` |
| **Port** | HA 的連接埠,預設 8123 | `8123` |
| **Long-Lived Token** | 貼上剛才複製的權杖 | (一長串文字) |

然後:

1. 按 **連線測試** —— 出現「已連線 ✓」代表位址與權杖都正確
2. 按 **儲存並連線** —— 卡片右上角的狀態標籤會變成 **已連線**

<blockquote style="border-left:4px solid #007AFF;background:#eff7ff;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#1c3d5a">
💡 測試失敗時先確認:面板與 HA 在同一個網段、IP 沒打錯、權杖沒有多複製到空白。權杖是一整段連續文字,中間不會有換行。
</blockquote>

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">6. 把 HA 裝置加進面板</h2>

連線成功後,在同一頁往下捲到 **Entity 挑選** 卡片。

1. 按 **載入 Entity 清單** —— 面板會向 HA 要一份可用裝置清單(裝置多時需要數十秒)
2. 用上方的**類別下拉**或**搜尋框**找到要的裝置
3. **勾選**要顯示在面板上的裝置,右上角會顯示 **已選 N / 24**
4. 按 **儲存** —— 面板磚牆會自動出現這些裝置

### 6.1 支援的裝置類別

面板只接受下列類別,清單上不會出現其他類別:

| 類別 | 面板上的樣子 |
|---|---|
| **light** 燈 | 依 HA 宣告自動判斷:只能開關的走整磚切換;可調光的可進控制頁調亮度、色溫、顏色 |
| **fan** 風扇 | 只能開關的走整磚切換;可調速的可進控制頁調風量、擺頭 |
| **cover** 窗簾 / 門 | 自動辨識:車庫門、大門走大磚(開/停/關);窗簾類可調開合百分比 |
| **lock** 門鎖 | 上鎖 / 解鎖,解鎖時磚會反白提醒 |
| **vacuum** 掃地機 | 電量顯示 + 清掃 / 暫停 / 回座 |
| **switch** 開關 | 點磚直接切換 |
| **climate** 空調 | 溫度大字 + 模式與風速選單 |
| **media_player** 播放器 | 播放 / 暫停 |
| **scene** 情境 | 點一下執行 |

<blockquote style="border-left:4px solid #007AFF;background:#eff7ff;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#1c3d5a">
💡 <b>清單上每個裝置右邊有一個小標籤</b>(例如「調光+色溫」「風量+擺頭」「位置」),那是面板讀取 HA 的能力宣告後判斷出來的。勾選前就能知道這台在面板上會有哪些功能。
</blockquote>

### 6.2 功能為什麼有差?

面板完全依照 **HA 提供的能力宣告**決定畫面。例如同樣是燈:

- HA 說它只能開關 → 面板就只給開關,不會有假的亮度滑桿
- HA 說它可調光、可調色溫 → 面板才會出現對應的滑桿

所以如果某台裝置在面板上少了功能,通常是 HA 那端的整合沒有宣告該能力,不是面板限制。

### 6.3 移除

回到 **HA導入** 分頁,取消勾選再按 **儲存**,磚牆就會移除。整組停用則按連線卡片的 **刪除設定**。

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">7. 面板操作</h2>

### 7.1 磚牆

- **點磚身** — 進入該裝置的控制頁
- **點左邊的圓形圖示** — 直接開關,不進控制頁
- **長按磚 1.5 秒** — 更換這台裝置的圖示(燈、風扇、窗簾類可換)
- **長按底部圖示 1.5 秒** — 更換該頁的頁腳圖示

### 7.2 齒輪頁

| 分頁 | 內容 |
|---|---|
| **桌布** | 四張桌布縮圖、磚塊透明度 / 灰度、螢幕亮度、睡眠時間 |
| **導入** | Automate裝置、版面排序、虛擬裝置、連網狀態、網路位置 |
| **面板** | 使用說明 / HomeKit 配對 / 面板後台 三個 QR,以及重置與重開機 |

### 7.3 排序

**齒輪 → 導入 → 版面排序**,拖曳即可調整磚牆順序。

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">8. 重置</h2>

重置會清除連線與配對設定,回到剛開箱的狀態。

### 8.1 怎麼重置

1. 面板上進入 **齒輪 → 面板** 分頁
2. 找到下方的 **長按10秒重置連網** 按鈕
3. **按住不放約 10 秒**(中途放開即取消,不會執行)
4. 時間到後面板自動清除並重新啟動

重啟後面板會再次開啟 `automate-smartlink-XXXXXX` 熱點,依[第 2 章](#2-初次設定連上-wi-fi)重新設定。

### 8.2 會清除 / 會保留什麼

| 項目 | 重置後 |
|---|---|
| Wi-Fi 帳號密碼 | ✅ 清除 |
| HomeKit 配對 | ✅ 清除 |
| Home Assistant 位址與權杖 | ✅ 清除 |
| 已匯入的 HA 裝置清單 | ✅ 清除 |
| Automate 裝置勾選與磚牆順序 | ✅ 清除 |
| 桌布 / 亮度 / 睡眠等偏好 | ✅ 清除 |
| 韌體版本 | ❌ 不變 |
| 出廠資料(配對碼、製造日期) | ❌ 保留 |

<blockquote style="border-left:4px solid #ff6f48;background:#fff7f4;padding:14px 18px;margin:16px 0;border-radius:0 12px 12px 0;color:#5a3520">
⚠️ 重置會讓面板從 Apple 家庭中失聯。重新配對前,請先在家庭 App 中把舊的面板配件移除,否則會出現「無回應」的殘留項目。
</blockquote>

### 8.3 只想重開機

同一個位置右邊有 **重開機** 按鈕,點一下即重啟,**不會清除任何設定**。畫面卡住或連線異常時先試這個。

<h2 style="color:#1c3d5a;border-bottom:3px solid #ff6f48;padding-bottom:8px;margin-top:48px;font-size:28px">10. 故障排除</h2>

### 10.1 Wi-Fi / 連線

| 現象 | 處理 |
|---|---|
| 找不到 `automate-smartlink-XXXXXX` 熱點 | 面板可能已連上網路(熱點只在未設定時出現)。看齒輪 → 導入 → 網路位置是否有 IP;要重設就依第 8 章重置 |
| 設定頁沒有自動跳出 | 瀏覽器手動開 `http://192.168.4.1`;部分手機需關閉行動數據 |
| 輸入密碼後連不上 | 確認是 2.4 GHz、密碼正確、路由器沒有開啟裝置隔離(AP Isolation) |
| 連網狀態顯示 `--` | 面板未連上 Wi-Fi,依第 2 章重新設定 |

### 10.2 Home Assistant

| 現象 | 處理 |
|---|---|
| 連線測試失敗 | 檢查 IP 有沒有打錯、Port 是否為 8123、面板與 HA 是否同網段 |
| 顯示 Token 無效 | 權杖複製不完整或已在 HA 端刪除,重新建立一組再貼 |
| 載入 Entity 清單很久 | HA 裝置多時屬正常,請耐心等候 |
| 清單裡找不到某台裝置 | 面板只收[第 6.1 節](#61-支援的裝置類別)列出的類別 |
| 匯入的裝置顯示「離線」 | 該裝置在 HA 端就是離線 / 不可用狀態 |
| 面板上某功能不見了 | HA 端未宣告該能力,見[第 6.2 節](#62-功能為什麼有差) |

### 10.3 面板 / 配對

| 現象 | 處理 |
|---|---|
| 家庭 App 顯示「無回應」 | 先確認面板有連上網路;仍異常則重開機(第 8.3 節) |
| 掃不到 HomeKit QR | 用「沒有代碼或無法掃描」手動輸入 QR 下方的配對碼 |
| 網頁打不開 | 確認手機與面板同網段;IP 可能因路由器重新配發而改變,回面板看網路位置 |
| 螢幕自動變暗 | 正常,睡眠時間可在齒輪 → 桌布 調整,拉到最右為恆亮 |
