<a id="wifi-setup"></a>
## 🌐 初次使用 Wi-Fi 設定

**藍色 LED 每秒閃一次** = 尚未設定 Wi-Fi

1. 手機 Wi-Fi 搜尋並連接熱點 **`Sonoff-S31-XXXXXX`**
2. 自動彈出品牌設定頁(未彈出時,瀏覽器開 `http://192.168.4.1`)
3. 點「掃描」→ 選擇家中 2.4GHz Wi-Fi → 輸入密碼 → 點「連線」
4. 裝置重啟自動連線;**藍 LED 熄滅 = 連線成功**

> 僅支援 2.4GHz Wi-Fi;設定頁同時顯示裝置序號與 HomeKit 設定碼。

<a id="homekit-pairing"></a>
## 📱 HomeKit 配對指南

1. 開啟 iPhone **「家庭」App** → 右上 **＋ → 加入配件**
2. 掃描本頁最上方 QR Code,或點「更多選項…」選取 `插座-XXXXXX`
3. 輸入配對碼 **`111-88-999`**
4. 分配房間,完成!

配對後家庭 App 內會看到:
- **插座開關**(含「使用中」狀態:負載 >1W 自動亮起)
- **按鈕 1 / 按鈕 2**:洗衣提醒事件來源(見[洗衣完成語音提醒](#washer))
- 以 **Eve App** 開啟可額外看到電壓 / 電流 / 功率 / 累積用電

<a id="button-led"></a>
## 🛠️ 按鍵與 LED 指示

| 操作 | 效果 |
|------|------|
| 短按 | 切換插座開 / 關 |
| 按住 5 秒 | 藍 LED 開始快閃 = 重置倒數警示(此時放開 = 取消) |
| 按住滿 10 秒 | **重置連網**:清除 Wi-Fi 設定並重啟回配網模式 |

| 藍色 LED | 含義 |
|------|------|
| 慢閃(1 秒) | 配網模式,或 Wi-Fi 斷線重連中 |
| 熄滅 | 正常運作(已連網) |
| 快閃 | 按住按鍵 5 秒後的重置警示 |

> 紅色 LED 恆跟隨繼電器:插座通電時亮。

<a id="washer"></a>
## 🔔 洗衣完成語音提醒

把洗衣機插在 S31 上,免改裝即可獲得「洗衣完成」通知:

**原理**:功率突破「待機功率 + 5W」= 開始洗衣 → 觸發 **按鈕 1**;
洗衣中功率低於待機門檻持續設定分鐘數 = 洗衣完畢 → 觸發 **按鈕 2**。

**設定(Web 首頁「語音提醒」卡)**:
1. 打開卡片右上開關啟用
2. 待機功率:選 5 / 8 / 10 / 15W,或按「取現在數值」自動選擇
3. 低功率持續分鐘:10–60 分鐘(建議 30,避開脫水間歇誤判)
4. 儲存

**家庭 App 自動化**:
1. 進入配件設定 → **按鈕 1** →「單次按下」→ 加入自動化 → HomePod 播報「洗衣開始」
2. **按鈕 2** →「單次按下」→ HomePod 播報「衣服洗好了」

狀態徽章會即時顯示:待機監測中 / 洗衣中(含低功率累計時間)。

<a id="mqtt"></a>
## 🏠 Home Assistant / MQTT 接入(選用)

底部第三個分頁(齒輪圖示)內有 **MQTT / Home Assistant** 設定卡:

1. 填入 Broker IP / Port / 帳號密碼 → 點「連線測試」
2. 測試成功後點「儲存並啟用」
3. HA 會自動探索出:插座開關、電壓 / 電流 / 功率 / 用電量感測器、
   洗衣提醒設定(開關 / 待機功率 / 分鐘)、來電狀態、洗衣狀態、
   累積用電歸零按鈕,以及「洗衣開始 / 完畢」兩個自動化觸發源

不需要時可「停用」(設定保留)或「刪除設定」。

<a id="ota"></a>
## 🔄 韌體更新 (OTA)

Web 底部分頁「**版更**」:

1. 自動顯示目前版本 / 最新版本與狀態徽章
2. 有新版時按「開始更新」:瀏覽器自動下載韌體並寫入裝置
3. 更新中**請勿斷電**;完成後裝置自動重啟,設定與配對全部保留

<a id="reset"></a>
## ♻️ 重置連網

- **實體按鍵**:按住 10 秒(5 秒起快閃警示)→ 清除 Wi-Fi 設定 → 回到配網模式
- 重置連網**不會**清除 HomeKit 配對與累積用電
- 要完全移除 HomeKit 配對:在家庭 App 內刪除該配件

<a id="troubleshooting"></a>
## 🔍 故障排除

| 症狀 | 處理 |
|------|------|
| 找不到 `Sonoff-S31-XXXXXX` 熱點 | 確認藍 LED 慢閃;否則按住按鍵 10 秒重置連網 |
| 家庭 App 顯示「無回應」 | 確認 Wi-Fi 訊號%(Web 首頁):紅色 <50% 請移近 AP 或換插座位置;並更新到最新韌體 |
| 電壓 / 功率顯示 0 | 插座未開或無負載屬正常;電壓恆 0 請確認已插上市電 |
| 洗衣提醒誤報完成 | 把「低功率持續分鐘」調大(脫水間歇會短暫低功率) |
| 配對碼無效 | 配對碼固定為 `111-88-999`;若曾配對過,先在家庭 App 刪除舊配件 |
| 網頁打不開 | 從路由器確認裝置 IP;或找主機名 `automate-s31-xxxxxx` |
